## Lista inicial de requisitos esenciales

- R01 · El estudiante solo accede a sus datos y a recursos habilitados para su condición.
- R02 · El investigador administra códigos, grupos y versiones sin mezclar diagnóstico con pretest.
- R03 · Un ejercicio conserva parámetros, respuesta esperada, dominio y versión para reproducir un intento.
- R04 · La retroalimentación y calificación siguen reglas verificables; la práctica dispone de pistas sin API generativa.
- R05 · El selector adapta la práctica con reglas documentadas y conserva la razón de recomendación.
- R06 · Las simulaciones tienen objetivo pedagógico y preguntas asociadas.
- R07 · El sistema registra intentos e impide duplicarlos por reenvío accidental.
- R08 · Encuesta, evaluaciones externas y práctica se exportan separadamente con códigos comunes.
- R09 · Recursos pendientes de revisión no se publican a estudiantes.
- R10 · Existe respaldo y se verifica su restauración antes del piloto.

En fase 2 cada requisito se convertirá en casos de aceptación y tareas de implementación. No se considera implementado ninguno de estos requisitos.
